## 🎭 La Storia

Un giorno ero annoiato. Mio nonno aveva bisogno di dividere le bollette del gas tra i coinquilini.

**Risultato?** Un'applicazione web con più effetti cinematografici di un film Marvel.

> *"Non avevo bisogno di una sirena nucleare quando la bolletta supera €2000, ma eccola qui."*

## 🚀 Quick Start

### Option 1: GitHub Pages
```
👉 https://sebascode.github.io/calcologas/
```

### Option 2: Direct Download
1. Scarica `dist/index.html`
2. Apri il file (funziona offline!)

### Option 3: Development
```bash
git clone https://github.com/sebascode/calcologas.git
cd calcologas
npm install
npm run dev
```

### Build
```bash
npm run build
# Output: dist/index.html (~570KB single file)
```

## 🛠️ Tech Stack

```
React 18 + TypeScript + Vite
├── 🎨 Tailwind CSS          → Design system
├── 🎬 Framer Motion         → Animazioni entry/exit
├── 🧩 shadcn/ui             → Componenti premium
├── 🔊 Web Audio API         → Suoni sintetizzati
├── 📳 Vibration API         → Haptic feedback
├── 🌊 WebGL + GLSL          → Shader acqua GPU
├── 📋 Web Share API         → Share nativo mobile
└── 📦 vite-plugin-singlefile → Build singolo file
```
